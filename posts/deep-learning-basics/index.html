模型预测错了，可以用损失（Loss）衡量预测与真实值的差距。但 Loss 只是一个数，怎样从这个数知道每个参数该改多少？

定义 Loss、确定候选函数集合、优化参数，再通过验证（Validation）和测试（Testing）检查效果，是机器学习的“3＋1”流程。

从一次错误的预测开始

假设只有一条样本：输入 x=2x=2x=2，真实值（标签）y=5y=5y=5。用 y^\hat yy^​ 表示模型的预测值，模型是：

y^=wx+b\hat y=wx+by^​=wx+b

www 是权重，决定直线的斜率；bbb 是偏置，决定它上下平移多少。取初始参数 w=1,b=0w=1,b=0w=1,b=0，得到：

y^=1×2+0=2\hat y=1\times2+0=2y^​=1×2+0=2

用当前参数算出预测值，叫作前向传播（forward propagation）。预测是 2，真实值是 5，可以用平方误差衡量这次预测：

L=(y^−y)2=(2−5)2=9L=(\hat y-y)^2=(2-5)^2=9L=(y^​−y)2=(2−5)2=9

多条样本的误差如果直接相加，正负可能抵消。先平方再取平均，就得到均方误差（Mean Squared Error，MSE）：

L=1N∑i=1N(y^i−yi)2L=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2L=N1​i=1∑N​(y^​i​−yi​)2

NNN 是样本数，y^i,yi\hat y_i,y_iy^​i​,yi​ 分别是第 iii 条样本的预测值和真实值。平方使较大的误差受到更大的惩罚，也让 MSE 对异常值更敏感。

把 y^i=wxi+b\hat y_i=wx_i+by^​i​=wxi​+b 代进去：

L(w,b)=1N∑i=1N(wxi+b−yi)2L(w,b)=\frac{1}{N}\sum_{i=1}^{N}(wx_i+b-y_i)^2L(w,b)=N1​i=1∑N​(wxi​+b−yi​)2

数据固定以后，Loss 就成了 w,bw,bw,b 的函数。改变参数会改变预测，也会改变 Loss；训练要找到能让它下降的改法。

从误差算到梯度

对开头的单个样本，预测和损失分别是：

y^=wx+b,L=(y^−y)2\hat y=wx+b,\qquad L=(\hat y-y)^2y^​=wx+b,L=(y^​−y)2

固定数据和 bbb，只让 www 发生微小变化，Loss 对 www 的变化率称为偏导数，记作 ∂L/∂w\partial L/\partial w∂L/∂w。

www 先影响预测值 y^\hat yy^​，再通过 y^\hat yy^​ 影响 Loss。链式法则将这条路径上两步的变化率相乘：

∂L∂w=∂L∂y^∂y^∂w=2(y^−y)x\frac{\partial L}{\partial w} =\frac{\partial L}{\partial\hat y} \frac{\partial\hat y}{\partial w} =2(\hat y-y)x∂w∂L​=∂y^​∂L​∂w∂y^​​=2(y^​−y)x

bbb 对预测值的导数是 1，因此：

∂L∂b=2(y^−y)\frac{\partial L}{\partial b} =2(\hat y-y)∂b∂L​=2(y^​−y)

代入 x=2,y=5,w=1,b=0x=2,y=5,w=1,b=0x=2,y=5,w=1,b=0：

∂L∂w=2(2−5)×2=−12,∂L∂b=2(2−5)=−6\frac{\partial L}{\partial w}=2(2-5)\times2=-12,\qquad \frac{\partial L}{\partial b}=2(2-5)=-6∂w∂L​=2(2−5)×2=−12,∂b∂L​=2(2−5)=−6

例如，固定 bbb，把 www 增加很小的 Δw\Delta wΔw，Loss 的变化约为 −12Δw-12\Delta w−12Δw。负号说明此处增大 www 能减小 Loss；bbb 的偏导也是负数，所以此处增大 bbb 同样能让 Loss 下降。

所有参数的偏导数组成梯度。记 θ=(w,b)\theta=(w,b)θ=(w,b)，此时：

∇θL=[∂L/∂w∂L/∂b]=[−12−6]\nabla_\theta L= \begin{bmatrix} \partial L/\partial w\\ \partial L/\partial b \end{bmatrix} = \begin{bmatrix} -12\\ -6 \end{bmatrix}∇θ​L=[∂L/∂w∂L/∂b​]=[−12−6​]

在通常的欧氏距离下，梯度指向当前位置局部上升最快的方向，负梯度指向局部下降最快的方向。∂L/∂w\partial L/\partial w∂L/∂w 只是其中一个分量。

多条样本使用平均 Loss，各个样本的梯度也相应取平均：

∂L∂w=2N∑i=1N(wxi+b−yi)xi,∂L∂b=2N∑i=1N(wxi+b−yi)\frac{\partial L}{\partial w} =\frac{2}{N}\sum_{i=1}^{N}(wx_i+b-y_i)x_i,\qquad \frac{\partial L}{\partial b} =\frac{2}{N}\sum_{i=1}^{N}(wx_i+b-y_i)∂w∂L​=N2​i=1∑N​(wxi​+b−yi​)xi​,∂b∂L​=N2​i=1∑N​(wxi​+b−yi​)

把乘法、加法、平方等运算作为节点，按数据依赖关系连接起来，就得到计算图。上面的计算依次经过 wxwxwx、wx+bwx+bwx+b、减去 yyy 和平方，梯度可以沿这些依赖反向计算。

反向传播（Backpropagation）从 Loss 出发，沿计算图反向应用链式法则，算出各个参数的梯度。有分支时，各条路径的梯度贡献需要相加。这个过程完成后，参数还没变；优化器再按选定的规则，利用梯度更新参数。下面使用的更新规则是梯度下降。

学习率决定迈多大一步

梯度下降用下面的式子更新参数：

θt+1=θt−η∇θL(θt)\theta_{t+1}=\theta_t-\eta\nabla_\theta L(\theta_t)θt+1​=θt​−η∇θ​L(θt​)

ttt 是更新次数，η\etaη 是学习率（learning rate）。取 η=0.1\eta=0.1η=0.1：

wnew=1−0.1×(−12)=2.2w_{\mathrm{new}}=1-0.1\times(-12)=2.2wnew​=1−0.1×(−12)=2.2 bnew=0−0.1×(−6)=0.6b_{\mathrm{new}}=0-0.1\times(-6)=0.6bnew​=0−0.1×(−6)=0.6

两个梯度都用更新前的同一组参数计算。再用新参数预测：

y^new=2.2×2+0.6=5,Lnew=0\hat y_{\mathrm{new}}=2.2\times2+0.6=5,\qquad L_{\mathrm{new}}=0y^​new​=2.2×2+0.6=5,Lnew​=0

这次恰好一步把 Loss 降到了 0，是样本、初始参数和学习率共同作用的结果。只有一个样本，却有两个参数，所有满足 2w+b=52w+b=52w+b=5 的参数组合都能拟合它。这些直线在其他输入上的预测可以完全不同。

如果从相同的初始参数出发，把学习率改成 η=0.3\eta=0.3η=0.3，更新后就会得到：

wnew=4.6,bnew=1.8,y^new=11,Lnew=36w_{\mathrm{new}}=4.6,\qquad b_{\mathrm{new}}=1.8,\qquad \hat y_{\mathrm{new}}=11,\qquad L_{\mathrm{new}}=36wnew​=4.6,bnew​=1.8,y^​new​=11,Lnew​=36

更新方向没变，Loss 却从 9 增加到了 36。梯度给的是局部信息，步子太大就可能越过低点。学习率过小则可能让训练很慢。

从一个样本到一批数据

训练集由成对的输入和标签 (xi,yi)(x_i,y_i)(xi​,yi​) 组成。每次更新可以使用整份数据，也可以只取其中一部分。

数据多起来以后，整个训练集一起计算可能超过显存容量；一次只处理一个样本，又可能用不满并行计算资源。因此通常把数据分成小批次（mini-batch，简称 batch），用当前 batch 的平均 Loss 求梯度，再更新参数。

更新方式 每次使用的数据
全批量梯度下降 整个训练集
随机梯度下降（Stochastic Gradient Descent，SGD，狭义） 随机抽取的一个样本
小批量随机梯度下降 一个 mini-batch

实践中说“用 SGD 训练”，经常也包括小批量的情况。

batch 指一次送入模型的一批数据；batch size（批量大小）是每批的样本数；optimizer step（优化器更新步）是一次参数更新；epoch（训练轮次）是训练集完整遍历一遍。例如有 1000 条样本，batch size 为 100，每个 batch 更新一次，那么一个 epoch 就有 10 次更新，20 个 epoch 共更新 200 次。

样本数不能整除 batch size 时，最后一批通常会小一些，也可以配置为丢弃。使用梯度累积时，则会处理多个 batch 才更新一次参数，所以日志中的 step（步骤）或 iteration（迭代）需要结合代码判断。

对于可以独立采样的数据，每个 epoch 开始时通常会随机打乱样本顺序（shuffle），让不同轮次的 batch 组成发生变化，减少固定排序对更新过程的影响。打乱的是成对的 (xi,yi)(x_i,y_i)(xi​,yi​)；时间序列或有状态训练要另外考虑时序，不能直接照搬。

不同 batch 的难度和梯度不同，Loss 曲线会有波动。相比某一步是否下降，一段时间内的趋势更有参考价值。

w,bw,bw,b 这类参数由训练学习；学习率、batch size、训练轮数等由人或外部搜索过程设置，称为超参数。

直线不够用时，为什么需要非线性激活函数

不管更新多少次 w,bw,bw,b，y^=wx+b\hat y=wx+by^​=wx+b 始终是一条直线。写下这个模型时，其实已经限定了候选函数集合：

F={x↦wx+b∣w,b∈R}\mathcal F=\{x\mapsto wx+b\mid w,b\in\mathbb R\}F={x↦wx+b∣w,b∈R}

每组参数对应集合中的一个函数。训练是在这个集合里寻找合适的直线；如果需要拟合的关系明显弯曲，最好的直线也可能留下很大的误差。换优化器不会改变这个限制。

输入和输出都有多个数值时，可以把标量形式的 wx+bwx+bwx+b 写成 Wx+bWx+bWx+b：xxx 是输入向量，WWW 是权重矩阵，bbb 是偏置向量。WWW 的每一行对输入做一次加权求和，再加上对应的偏置，得到一个输出分量。这样的计算在神经网络中称为线性层。

把一层的输出送入下一层，如果两层都只计算 Wx+bWx+bWx+b，就能合并成一层。下标和偏置上的括号表示层号：

W2(W1x+b(1))+b(2)=(W2W1)x+(W2b(1)+b(2))W_2(W_1x+b^{(1)})+b^{(2)} =(W_2W_1)x+(W_2b^{(1)}+b^{(2)})W2​(W1​x+b(1))+b(2)=(W2​W1​)x+(W2​b(1)+b(2))

严格说，WxWxWx 是线性变换，加上偏置后的 Wx+bWx+bWx+b 称为仿射变换。上式说明，直接叠加这样的层，仍然表示不了一般的非线性关系。

激活函数接在线性层之后，对计算结果再做一次变换。使用非线性的激活函数，可以让多层网络表示更复杂的关系。修正线性单元（Rectified Linear Unit，ReLU）是一种常用选择，它在 0 处加入了一个折点：

ReLU⁡(z)=max⁡(0,z)\operatorname{ReLU}(z)=\max(0,z)ReLU(z)=max(0,z)

输入小于 0 时输出 0，大于 0 时保留原值。把几个位置不同的 ReLU 加权相加，就能改变不同区间的斜率。例如：

f(x)=ReLU⁡(x)−2ReLU⁡(x−1)+ReLU⁡(x−2)f(x)=\operatorname{ReLU}(x)-2\operatorname{ReLU}(x-1)+\operatorname{ReLU}(x-2)f(x)=ReLU(x)−2ReLU(x−1)+ReLU(x−2)

三个折点分别在 0,1,20,1,20,1,2。把各项代进去：

f(x)={0,x<0x,0≤x<12−x,1≤x<20,x≥2f(x)= \begin{cases} 0,&x<0\\ x,&0\le x<1\\ 2-x,&1\le x<2\\ 0,&x\ge2 \end{cases}f(x)=⎩⎨⎧​0,x,2−x,0,​x<00≤x<11≤x<2x≥2​

在 1≤x<21\le x<21≤x<2 时，前两项已经激活，第三项仍是 0，所以 f(x)=x−2(x−1)=2−xf(x)=x-2(x-1)=2-xf(x)=x−2(x−1)=2−x。到了 x≥2x\ge2x≥2，三项恰好抵消。总斜率从 0 变成 1，再变成 −1，最后回到 0，拼出了一段先上升、再下降的折线，最高点是 (1,1)(1,1)(1,1)。

这里的参数是手动选好的，用来说明函数怎样构成，不是训练结果。四个小图的纵轴范围不同，应按公式比较斜率，不能直接比较线段的倾斜角度。

模型能表示，不等于训练能找到

机器学习基础课件《BasicML》（ML 为 Machine Learning，即机器学习）用投影片页数预测课程时长：线性模型的训练 Loss 约为 71，换成有 100 个隐藏神经元的网络后，训练 Loss 反而约为 80；调整超参数后才降到约 41。

把全部参数记作 θ\thetaθ，训练目标通常写成：

θ∗∈arg min⁡θLtrain(θ)\theta^*\in\operatorname*{arg\,min}_\theta L_{\mathrm{train}}(\theta)θ∗∈θargmin​Ltrain​(θ)

arg⁡min⁡\arg\minargmin 表示取得最小值的参数集合；可能有多组最优参数，所以这里用 ∈\in∈。全局最小值（Global Minimum）是在全部允许的参数中比较得到的最低 Loss；局部极小值（Local Minimum）只要求在某组参数附近，没有更低的 Loss。上式写的是全局优化目标，实际训练未必能达到。

如果大模型的候选集合包含小模型的全部函数，且使用相同训练数据和损失，理论上有：

inf⁡f∈FlargeLtrain(f)≤inf⁡f∈FsmallLtrain(f)\inf_{f\in\mathcal F_{\text{large}}}L_{\mathrm{train}}(f) \le \inf_{f\in\mathcal F_{\text{small}}}L_{\mathrm{train}}(f)f∈Flarge​inf​Ltrain​(f)≤f∈Fsmall​inf​Ltrain​(f)

inf⁡\infinf 表示能达到或无限接近的下界。原来的函数都还在，最好的可能结果就不会更差。但实际训练只得到了某组参数，未必到达这个下界。大模型训练得更差时，需要检查优化过程、实现和比较设置，不能直接归因于表达能力不足。

前面用 wx+bwx+bwx+b 预测数值的模型属于线性回归。它配合 MSE 时，Loss 关于参数是凸函数：任取两组参数，将它们的损失点用线段相连，沿两组参数之间直线计算出的 Loss 都不高于这条线段。凸函数的局部极小值也是全局最小值。最优参数可能不唯一，例如输入特征存在冗余；学习率不合适时，梯度下降也可能不收敛。

神经网络的 Loss 通常是非凸的。参数初始化就是选择训练开始时的参数值，不同初始值可能让优化走出不同的路径。图中还标出了 Saddle Point（鞍点），其多方向的含义在图后解释：

这是一张非凸损失的简化示意图，不是前面线性回归的 MSE 曲线。真实网络有很多参数，Loss 定义在高维参数空间里。

梯度接近 0 可能出现在局部极小值、局部极大值、鞍点或较平坦的区域。鞍点附近，沿某些方向向上，沿另一些方向却能继续向下。深层网络还可能遇到梯度消失或梯度爆炸：梯度在逐层反向传播时变得过小，可能使前面层的参数几乎不更新；变得过大，则可能导致更新不稳定。不同方向上的变化尺度也可能差异很大。初始化、数据顺序、学习率和优化器都会影响训练路径。

训练 Loss 很低之后，还要看什么

假设造一个“记答案”的函数：遇到训练样本就返回记住的标签，其他输入一律返回 0。它在训练集上的 Loss 可以是 0，但换一批数据就可能错得很严重。

这就是泛化问题：模型对没见过的数据表现怎样。课件中的课程时长模型增加特征后，训练 Loss 约为 22，验证 Loss 却约为 1307。训练拟合得更好，没有带来相应的验证效果。

数据划分 用途
训练集 计算训练 Loss，通过梯度更新参数
验证集 比较模型、选择超参数、判断何时停止训练
测试集 在模型和设置确定后，评估最终效果

过拟合指模型过度适应了训练数据中的细节或噪声，在新数据上的表现较差。例如训练 Loss 持续下降，验证 Loss 却开始回升，就可能已经过拟合：

图中只画趋势，不是实验记录。早停是根据验证表现决定何时结束训练的方法，通常会容忍若干轮没有改善，再停止训练，恢复验证表现较好的检查点。检查点保存了某次训练时的模型参数，也可以包含优化器等训练状态。

欠拟合指模型尚未充分学到数据中的规律，连训练数据也拟合不好。训练和验证都差，可能是欠拟合，也可能是数据、训练设置或实现有问题；训练很好而验证明显较差，除了过拟合，也要检查两份数据是否存在分布差异。单凭一条验证曲线，不能确定全部原因。

课程时长的例子最初用 2021 年的课程数据预测 2025 年的课程，后来改用了更接近的 2024 年数据。训练数据和目标场景不合适时，在旧数据上继续压低 MSE，也未必能改善目标场景下的预测。

出现过拟合时，除了早停，还可以检查数据的质量和数量。数据增强会对已有样本做保持标签含义的变换，例如对适合翻转的图片做水平翻转；调整模型容量，则是改变模型能表示的函数范围，例如减少隐藏神经元。

正则化通过额外约束或训练设置限制过拟合，例如在损失中加入权重平方和的惩罚。Dropout（随机失活）也是一种正则化方法：训练时随机将部分神经元的输出置零，减少网络对特定中间输出的依赖。

评估数据也要与训练隔离。例如，常见的特征标准化会先减去均值，再除以标准差，让不同特征的数值尺度更接近。均值和标准差应只从训练集估计，再用于处理验证集和测试集；标准差为 0 的特征需要单独处理。

验证集也会被反复调参用熟

验证集不直接参与梯度更新，但每次根据验证结果修改模型、特征或超参数，都在利用它选择方案。尝试得足够多，可能选出一个恰好适合这份验证集、对新数据却没有同样优势的模型。

因此，测试集要留到模型和设置确定后再用。如果看完测试结果又继续调参，这份测试集也参与了模型选择，后续就需要新的独立数据评估。

分类：从类别分数到交叉熵

前面的回归模型预测一个数值。换成图片分类，假设每张图片只属于“猫、狗、兔”中的一类，模型需要给出三个类别各自的分数，再根据真实标签计算 Loss。

标签和模型输出怎样对应

固定类别顺序为“猫、狗、兔”，可以用编号 0,1,20,1,20,1,2 保存标签。编号只用于区分类别，本身没有大小或距离的含义。计算损失时，也可以把标签写成独热编码（one-hot）：真实类别的位置为 1，其余位置为 0。

类别 编号 独热标签
猫 0 (1,0,0)(1,0,0)(1,0,0)
狗 1 (0,1,0)(0,1,0)(0,1,0)
兔 2 (0,0,1)(0,0,1)(0,0,1)

假设当前图片是一只狗，标签向量就是 y=(0,1,0)y=(0,1,0)y=(0,1,0)。这里 yyy 的每个分量对应一个类别；前面的回归例子中，yyy 是一个标量。

网络最后一层可以用线性变换输出三个分数：

z=Wouth+boutz=W_{\mathrm{out}}h+b_{\mathrm{out}}z=Wout​h+bout​

hhh 是隐藏层输出。若 hhh 有 mmm 个分量，这里的 WoutW_{\mathrm{out}}Wout​ 就是 3×m3\times m3×m 的矩阵。这三个未经归一化的分数称为 logits，可以为任意实数，也不要求加起来等于 1。

假设这次输出：

z=(1,2,0)z=(1,2,0)z=(1,2,0)

“狗”的分数最高。只需要选出预测类别时，直接取 logits 最大值的位置即可；要计算类别概率，还需要 softmax（归一化指数函数，将一组分数转成和为 1 的概率）。

softmax 把分数转成概率

对于 CCC 个类别，softmax 定义为：

pc=ezc∑k=1Cezkp_c=\frac{e^{z_c}}{\sum_{k=1}^{C}e^{z_k}}pc​=∑k=1C​ezk​ezc​​

每一项都大于 0，所有项的和为 1。代入这次的 logits：

p=(e1,e2,e0)e1+e2+e0≈(0.2447, 0.6652, 0.0900)p=\frac{(e^1,e^2,e^0)}{e^1+e^2+e^0} \approx(0.2447,\ 0.6652,\ 0.0900)p=e1+e2+e0(e1,e2,e0)​≈(0.2447, 0.6652, 0.0900)

模型分配给“狗”的概率约为 66.52%66.52\%66.52%，所以预测类别为“狗”。这个数表示模型当前给出的概率估计，是否与实际正确率相符，还需要用数据检验。

softmax 由各类别分数的相对差异决定。给所有 logits 加上相同常数，概率保持不变。计算时常先减去最大值：

pc=ezc−a∑k=1Cezk−a,a=max⁡kzkp_c=\frac{e^{z_c-a}}{\sum_{k=1}^{C}e^{z_k-a}}, \qquad a=\max_k z_kpc​=∑k=1C​ezk​−aezc​−a​,a=kmax​zk​

预测已经正确，为什么 Loss 还大于 0

对独热标签 yyy 和预测概率 ppp，单个样本的交叉熵（cross-entropy）为：

这里使用自然对数。只有真实类别的位置满足 yc=1y_c=1yc​=1，其余项都为 0。记真实类别的位置为 ttt，公式就简化为：

ℓ=−log⁡pt\ell=-\log p_tℓ=−logpt​

这张图片的真实类别是“狗”，因此：

ℓ=−log⁡0.6652409558≈0.4076\ell=-\log 0.6652409558\approx0.4076ℓ=−log0.6652409558≈0.4076

虽然预测类别已经正确，模型仍给其他类别分配了概率。真实类别的概率越接近 1，交叉熵越接近 0；概率越接近 0，损失越大。例如把“狗”的概率从当前值提高到 0.90.90.9，损失就会降到约 0.10540.10540.1054。

准确率是预测正确的样本数占总样本数的比例。交叉熵还会随真实类别的概率变化，因此分类准确率不变时，Loss 仍然可能下降。

一张图片有多个标签时

前面每个样本只有一个正确类别，属于单标签分类。如果图片中可以同时出现猫和狗，就属于多标签分类。仍按“猫、狗、兔”的顺序，标签可以写成 y=(1,1,0)y=(1,1,0)y=(1,1,0)，每个位置分别表示该类别是否出现。

模型仍输出三个 logits，但各类别分别用 sigmoid（S 形函数，这里指将实数映射到 0 与 1 之间的逻辑函数）转成概率：

pc=σ(zc)=11+e−zcp_c=\sigma(z_c)=\frac{1}{1+e^{-z_c}}pc​=σ(zc​)=1+e−zc​1​

sigmoid 将单个实数映射到 0 和 1 之间。三个概率分别计算，不要求和为 1，因此猫和狗的概率可以同时很高。预测时可对每一类设置阈值，例如将概率超过 0.50.50.5 的类别标记为出现；阈值也可以根据验证结果调整。

对每个类别，使用二元交叉熵（Binary Cross-Entropy，BCE）：

ℓc=−[yclog⁡pc+(1−yc)log⁡(1−pc)]\ell_c=-\left[y_c\log p_c+(1-y_c)\log(1-p_c)\right]ℓc​=−[yc​logpc​+(1−yc​)log(1−pc​)]

当 yc=1y_c=1yc​=1 时，损失为 −log⁡pc-\log p_c−logpc​；当 yc=0y_c=0yc​=0 时，损失为 −log⁡(1−pc)-\log(1-p_c)−log(1−pc​)。前者要求出现的类别概率高，后者要求未出现的类别概率低。各类别的损失可以再取平均，得到一个样本的损失。

PyTorch 的 nn.BCEWithLogitsLoss 将 sigmoid 和二元交叉熵合在一起，直接接收原始 logits。多标签情况下，logits 和浮点标签的形状都为 [样本数, 类别数]；默认对所有样本和类别的损失取平均。不要在传入前再做 sigmoid。参见 BCEWithLogitsLoss 文档。
